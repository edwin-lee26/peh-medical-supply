Backup your data

This page reads whatever is stored in this browser and packs it into a backup file. Open it in the same browser you used to type in your items, on the same PC or phone.

How to use:
1. Tap Create backup - a file msm-backup.json downloads and the text appears below.
2. Send that file (or copy the text below) to your developer.
3. Nothing on this page is sent anywhere - it only reads this device.
